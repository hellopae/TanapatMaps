# Tanapat Maps

เว็บแอปรวมสถานที่ส่งงาน Tanapat ภาษาไทย สำหรับมือถือและคอมพิวเตอร์

## ใช้งาน

เปิด `https://hellopae.github.io/TanapatMaps/` เมื่อเปิด GitHub Pages จาก `main` และ `/ (root)` แล้ว

- 36 รายการ: 34 สถานที่ธุรกิจพร้อมลิงก์แผนที่ และ 2 รายการส่วนบุคคลที่ซ่อนรายละเอียด
- ค้นหาชื่อ ย่าน รายละเอียด ผู้ติดต่อ หรือเบอร์โทร กรองประเภทและพื้นที่
- เปิด Google Maps จากลิงก์ที่ระบุในเอกสาร แล้วเลือกเส้นทาง / เริ่มนำทาง
- เพิ่ม แก้ไข ลบสถานที่ อัปโหลดรูป และเก็บสถานที่โปรด
- ส่งออก / นำเข้า JSON รวมรูปภาพ เพื่อสำรองข้อมูลหรือย้ายเครื่อง

ข้อมูลจากเอกสารส่งงานของ Tanapat และข้อมูลยืนยันจากเจ้าของงาน

เอกสารไม่มีรูปสถานที่ จึงแสดงภาพสัญลักษณ์พร้อมข้อความ “ยังไม่มีรูปสถานที่” และรองรับการเพิ่มรูปจริง ไม่ใช้รูปสมมติแทนสถานที่จริง

**ข้อมูลที่เพิ่ม/แก้ไขเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น ไม่ซิงก์ระหว่างผู้ใช้งานหรือเครื่อง และไม่ได้เขียนกลับ GitHub/Google Docs** กรุณาส่งออกสำรองก่อนล้างข้อมูลเบราว์เซอร์ ควรเพิ่ม backend เมื่อต้องการสมุดสถานที่ที่ทีมแก้ไขร่วมกัน

Aeon เป็นลูกค้าที่ตึก Modernform จึงรวมสองชื่อเป็นสถานที่เดียวตามที่ผู้ใช้ยืนยัน รายละเอียดส่วนบุคคลและพิกัดบ้านไม่เผยแพร่ใน repository สาธารณะ ประเภทสถานที่จัดกลุ่มเพื่อช่วยค้นหา พื้นที่แสดงเฉพาะที่ระบุในเอกสาร

## พัฒนา

เว็บ static HTML/CSS/JavaScript ไม่มีขั้นตอน build หรือ API key

```sh
python3 -m http.server 4173
node --check app.js
node --check data.js
```

เปิด http://localhost:4173

## ข้อมูลส่วนบุคคล

ไฟล์ `private/tanapat-maps-full.json` เก็บไว้เฉพาะในเครื่องและถูกละเว้นจาก Git ใช้ปุ่มนำเข้าข้อมูลบนเว็บเพื่อเพิ่มรายละเอียดฉบับเต็มลงในเบราว์เซอร์ของคุณเอง ห้าม commit ไฟล์นี้ลง repository สาธารณะ การนำเข้าไม่อัปโหลดข้อมูลไปยังเซิร์ฟเวอร์
